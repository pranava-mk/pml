03 / 06

how it works

Three moves. No lock-in.

01 — FILES

A deck is a folder

slides/01-title.html plus a shared theme.css. Every slide opens standalone in any browser, forever.

02 — SERVE

pml serve

One command: deck hub, overview grid, presenter mode with transitions, a full visual editor and comments — on localhost.

03 — SHARE

Export & collaborate

One-click export to a single self-contained HTML file. Pin comments, reply, resolve. Git is your history.

$ node pml/bin/pml.js new my-deck
$ node pml/bin/pml.js serve my-deck # → localhost:4321
